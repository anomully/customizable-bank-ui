# Customizable Bank UI

Customize the buttons along the bottom of the bank: their order, which ones show, how the row
fills space, button widths and divider lines.

The plugin moves the game's own buttons rather than drawing new ones, so every click,
right-click option, hover effect and highlight works exactly as normal.

## Layout

- **Drag to reorder**: while on, drag any button in the row onto another to move it there.
  Turn it off to lock the order.
- **Leftover space**: what the row does with space left by hidden buttons or removed dividers.
  - *Leave gaps*: hidden buttons keep their space; any other leftover space is spread evenly
    between the buttons.
  - *Collapse left* / *Collapse right*: buttons slide together; the space ends up on one side.
  - *Stretch to fill*: buttons widen to fill the row.
- **Uniform button widths**: makes the wider search button the same width as the rest.
- **Dividers**: between sections (the game's default), between every button, or none.

## Button visibility

Show or hide each button in the row: Rearrange mode, Withdraw as note, the 1 / 5 / 10 / X / All
quantity buttons, Placeholders, Search, Empty containers, Deposit inventory and Deposit worn items.
